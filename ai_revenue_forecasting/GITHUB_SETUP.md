# Publish this project to GitHub

1. Create a new **public** GitHub repository named `ai-revenue-forecasting`.
2. Extract this ZIP and open a terminal inside the extracted `ai_revenue_forecasting` folder.
3. Run:

```bash
git init
git add .
git commit -m "Build AI revenue forecasting capstone"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/ai-revenue-forecasting.git
git push -u origin main
```

4. Replace `YOUR-USERNAME` with your GitHub username.
5. Open the repository in a private/incognito window to confirm it is publicly accessible.
6. Submit the actual repository URL in Coursera. Do not submit the example URL.
